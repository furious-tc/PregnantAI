# BabyJoy - Приложение для беременных

## Описание
BabyJoy - это React Native приложение для поддержки беременных женщин на протяжении всего периода беременности. Приложение предоставляет персонализированные советы, трекинг развития малыша, AI-помощника и сообщество поддержки.

## Технологический стек

### Основные технологии
- **React Native + Expo** - кроссплатформенная разработка
- **TypeScript (strict)** - типизация
- **NativeWind** - Tailwind CSS для React Native
- **React Navigation** - навигация (stack + bottom tabs)

### Управление состоянием
- **Redux Toolkit** - глобальное состояние
- **RTK Query** - работа с API (планируется)

### UI и стили
- **NativeWind** - стилизация на основе Tailwind CSS
- **Собственная дизайн-система** с цветовой палитрой для беременных
- **FontAwesome** - иконки

### Формы и валидация
- **React Hook Form** - управление формами
- **Zod** - валидация схем

### Локализация
- **i18next** - поддержка 5 языков (ru, en, de, fr, es)
- **expo-localization** - автоопределение языка устройства

## Запуск проекта

1. Установите зависимости:
```bash
npm install
```

2. Запустите development server:
```bash
npm start
```

3. Используйте Expo Go на телефоне или эмулятор для тестирования

## Команды

- `npm start` - запуск Expo development server
- `npm run android` - запуск на Android эмуляторе
- `npm run ios` - запуск на iOS симуляторе (только macOS)
- `npm run web` - запуск в браузере

## Архитектурные принципы

1. **Feature-Sliced Design** - организация кода по функциональным модулям
2. **Компонентный подход** - переиспользуемые UI компоненты
3. **Типизация** - строгий TypeScript для надежности
4. **Локализация** - поддержка множества языков с самого начала
5. **Responsive Design** - адаптивность для разных размеров экранов
