# 🤱 BabyJoy - Приложение для беременных

## 📱 Описание
BabyJoy - это React Native приложение для поддержки беременных женщин на протяжении всего периода беременности. Приложение предоставляет персонализированные советы, трекинг развития малыша, AI-помощника Maya и сообщество поддержки.

## ✨ Особенности

### 🎯 Основные функции
- **📅 Календарь беременности** - отслеживание развития малыша по неделям
- **🤖 AI-помощник Maya** - персональные советы и поддержка 24/7
- **📖 Дневник беременности** - запись симптомов, настроения и важных моментов
- **📊 Трекинг здоровья** - вес, давление, движения малыша
- **👥 Сообщество мам** - группы поддержки и общение
- **🏆 Система достижений** - геймификация здорового образа жизни

### 🛠 Технологический стек
- **React Native + Expo** - кроссплатформенная разработка
- **TypeScript** - строгая типизация
- **Redux Toolkit** - управление состоянием
- **React Navigation** - навигация
- **Linear Gradient** - красивые градиенты
- **FontAwesome5** - векторные иконки
- **i18next** - локализация (5 языков)

## 🚀 Запуск проекта

### Требования
- Node.js 18+
- npm или yarn
- Expo CLI

### Установка и запуск
```bash
# Клонирование репозитория
git clone https://github.com/furious-tc/PregnantAI.git
cd PregnantAI/app/mobile

# Установка зависимостей
npm install

# Запуск development server
npm start

# Альтернативные команды
npm run android    # Android эмулятор
npm run ios        # iOS симулятор (только macOS)
npm run web        # Браузер
```

## 🔧 Архитектура

### Feature-Sliced Design
- **features/** - модули по функциям
- **shared/** - общие ресурсы
- **entities/** - типы данных

### Технические решения
- **Redux Toolkit** - состояние приложения
- **i18next** - мультиязычность
- **Expo Linear Gradient** - градиенты
- **React Hook Form + Zod** - формы (готово к использованию)
- **Анимации** без useNativeDriver для веб-совместимости
